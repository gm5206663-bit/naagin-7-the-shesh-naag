## Publishing to GitHub

Prepared and tested on 2026-11-11, on the author's authorisation. Nothing has been pushed yet: the push needs his token.

```
GITHUB_TOKEN=<fine-grained token with Contents + Administration: read and write> tools/publish_git.sh --push
```

- The repository is created on his account as **`naagin-7-the-shesh-naag`**, public, branch `main`, one commit.
- **Published:** the rulings, the canon digests and Episode 1's beat ledger, the foundation, the three chapters, the tools, Sara.
- **Not published:** the caption tracks, the recaps and the stills. Those are held in the workshop for checking only. The repository's `.gitignore` names them, so a later clone cannot add them by accident.
- Tested end to end against a local bare repository: build, commit, push, clone, and `check.py` green in the clone.

## Tools

| Script | Use |
|---|---|
| `tools/check.py` | `python3 tools/check.py` from this folder. Owner lines, cited rows, referenced files |
| `tools/publish_git.sh` | `tools/publish_git.sh` builds a clean git repository of the workshop in `/tmp/publish` and stops there; `GITHUB_TOKEN=<token> tools/publish_git.sh --push` creates the public repository on GitHub if it does not exist and pushes `main`. The raw record is never published: `captions/`, `canon/sources/` and `canon/frames/` are excluded by name and again by the repository's own `.gitignore` |
| `tools/camera_check.py` | `python3 tools/camera_check.py chapters/<file>` measures a chapter against `WRITING.md` §2: comparisons, the past tense and explained feeling in narration, the sixty-word cap, the share of speech; and it lists every feeling the narration names, so each one can be checked against the episode (`O019`). `--selftest` proves it on a fixture with planted faults |
| `tools/cite_check.py` | `python3 tools/cite_check.py 1 8` prints each cited caption time beside the caption text, for a person to compare |
| `tools/recap_find.py` | From `canon/sources`: `python3 ../../tools/recap_find.py tr:3 Rajat "glasses|bus"` finds a recap's sentences by word |
| `tools/caption_hits.py` | `python3 tools/caption_hits.py 'REGEX' [width] [max per episode] [E05,E06]` searches the caption text |
| `tools/read_recap.py` | From `canon/sources`: `python3 ../../tools/read_recap.py tr:9 tb:21` prints a recap's body |
| `tools/fetch_captions.sh`, `tools/json3_to_txt.py` | Fetch and convert a caption track from an official upload |
| `tools/contact_sheet.py` | Make a sheet of stills from a video file |
